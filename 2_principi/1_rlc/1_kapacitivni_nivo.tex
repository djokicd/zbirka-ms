\PID
Капацитивни сензор израђен од сегмента коаксијалног кабла дужине $\ell = 20\unit{cm}$ постављен је у мерни суд са водом 
пермитивности $\upepsilon_{\rm r}$ као што је 
приказано на слици. 
Пречник унутрашњег проводника сензора је $a = 10\unit{mm}$, а унутрашњи пречник спољашњег проводника је $b = 20\unit{mm}$. 
Величина која се мери је удаљеност слободне површине воде од руба суда, $0 < h < \ell$.
\begin{enumerate}[label=(\alph*)]
\item Одредити израз за капацитивност сензора 
у завивности од мерене величине, $C = C(h)$. Ивичне ефекте занемарити.
%
\item Релативна пермитивност воде зависна је од температуре. На температурама 
$t_1 =20^\circ\rm C$ и
$t_2 =80^\circ\rm C$ она износи 
$\upepsilon_{\rm r1} = 80$ и 
$\upepsilon_{\rm r2} = 60$, редом. Скицирати зависности $C = C(h)$ на истом графику за обе
температуре воде.
\end{enumerate}
\end{slikaDesno}

\RESENJE

(а)
Капацитивност коаксијалног кондензатора је дата изразом\footnote{Израз за капацтивност изводи се полазећи од 
електричног поља цилиндрично симетричне расподеле наелектрисања 
$E = \dfrac{Q'}{2\uppi\upepsilon r}$, а која се може добити из Гаусовог закона. 
Интеграцијом поља у границама од интереса добија се 
$U = \int_{r = a/2}^{b/2} E\,\de r = \dfrac{Q}{2\uppi\upepsilon} \ln\dfrac ba$, одакле се по дефиницији налази 
подужна капацитивност $C' = Q'/U$, па се укупна капацитивност налази множењем са дужином кондензатора 
$C = L Q'/U$, 
} $C = \dfrac{2\uppi\upepsilon L}{\ln(b/a)}$, где је 
$L$ дужина кондензатора, а $a$ и $b$ су унутрашњи и спољашњи пречник редом. У разматраном сензору, постоје 
две капацитивности, она која потиче од сегмента у ваздуху и она која потиче од сегмента уроњеног у воду. 
Ове две капацитивност везане су паралелно, па је $C = C_1 + C_2$. Појединачне капацитивности су онда 
\begin{equation}
    C_1 = \dfrac{2\uppi \upepsilon_0 h}{\ln(b/a)}, \qquad\text{и}\qquad
    C_2 = \dfrac{2\uppi \upepsilon_0 \upepsilon_{\rm r} (l-h)}{\ln(b/a)}
    \quad\Rightarrow  \quad
    C = \dfrac{2\uppi\upepsilon_0}{\ln(b/a)}
    (h + \upepsilon_{\rm r}(l-h))
\end{equation}
Сређивањем добијеног резултата има се 
\begin{equation}
    C = \dfrac{2\uppi \upepsilon_0}{\ln(b/a)} 
    (\upepsilon_{\rm r} l - (\upepsilon_{\rm r} - 1)h )
    = \underbrace{\dfrac{2\uppi\upepsilon_0 l \upepsilon_{\rm r}}
    {\ln(b/a)}}_{\upepsilon_{\rm r} C_0} \left( 1 - \dfrac{\upepsilon_{\rm r} - 1}{\upepsilon_{\rm r}} \dfrac hl \right),
\end{equation}
где је $C_0$ капацитивност кондензатора у када је потпуно испуњен ваздухом.

(б) Израз за капацитивност линеарно зависи од $h$, а том приликом је на граничним вредностима 
$C(h = 0) = \upepsilon_{\rm r} C_0$ и $C(h = \ell) = C_0$. Капацитивност у случају кондензатора 
испуњеног ваздухом не зависи од температуре па износи $C_0 = 16,05\unit{pF}$. Капацитивност у супротном 
случају зависи од температуре, и износи 
$C(h = 0) = 
\begin{cases}
    1,24\unit{nF}, & t = 20\rm^\circ C \\
    0,96\unit{nF}, & t = 80\rm^\circ C 
\end{cases}$. Тражени графици приказани су на слици \ref{fig:\ID:graf}. Према сликама се види, да капацитивност дела кабла у ваздуху
практично уопште не доприноси резултату мерења.
