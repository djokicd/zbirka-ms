\PID
У колу линеаризованог отпорног моста који се користи за мерење отпорности 
отпорног сензора $R_{\rm s}$ напон напајања је $V_{\rm CC} = 9\unit{V}$. 
Операциони појачавач је идеалан, а за отпорнсости важи 
$R_1 = R_2 = R_3 = R_0 = 10\unit{k\Omega}$, док је отпорност сензора $R_{\rm s} = R_0(1 + x)$, где је $x$ релативна промена 
отпорности сензора. 
\begin{enumerate}[label=(\alph*)]
\item Одредити распоред прикључака операционог појачавача, тако да у колу 
буде остварена негативна повратна спрега.
\item Одредити зависност излазног напона $v_I$ од релативне промене отпорности $x$.
\end{enumerate}
